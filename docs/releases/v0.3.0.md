# COV v0.3.0 — first stable release

The first stable release preserves the current head of PR #3. It includes the FCHK/FCH primary wavefunction interface, Molden input, CUDA/OpenGL rendering, scoped orbital chemistry, native validation, source-aware exports, and the reviewed physical-core scheduling changes.

Merged commit: `50b5cdb73369c1a4558c11c94d25d5494be308f0`.
PR #3 head: `d68ebdcdfc70a6e38aa2747ac231ced9e64c3bc6`.
Complete Git tree: `b715cc56ee7c064632fee6326cca28bb7341766f`.

## Run

Unzip the Windows-sm120 bundle and run cov.exe. Open or drag a FCHK/FCH or Molden file; examples/h2.molden is included. The packaged binary targets NVIDIA Blackwell sm_120 (tested on RTX 5090) and includes compute_120 PTX. It requires a compatible NVIDIA display driver and OpenGL 2.1. CUDA Toolkit is needed for source builds, not ordinary use. Other GPU architectures require a source build configured for that architecture.

## Release boundary

This stable release contains PR #3 only. The subsequent NBO/NAO/NHO/NLMO/SALC integration and R16 scientific-audit fixes are released separately as v0.4.0-pre.1. Existing reference-data archives are retained at their original release URLs.

No Gaussian, NBO, GenNBO, ORCA executable or proprietary runtime is bundled. Those programs are not required merely to visualize existing wavefunction files.
