# Chemical Orbital Visualiser v0.3.0

v0.3.0 is the stable release for exploring molecular orbitals from existing Gaussian FCHK/FCH or Molden files. Browse orbital energies and occupations, compare levels in an energy diagram, export figures and data, and inspect selected orbitals around the molecule in 3D.

## Get started

Download the Windows bundle from the [v0.3.0 release](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.3.0), unzip it and run `cov.exe`. Open or drag in an FCHK/FCH or Molden file; `examples/h2.molden` is included. COV reads existing results and does not include Gaussian, NBO or other quantum chemistry programs. CHK conversion requires a separately installed `formchk`.

The supplied Windows build is for RTX 50-series GPUs and requires a compatible NVIDIA driver and OpenGL 2.1. Other NVIDIA GPU architectures need a suitable [source build](../BUILD.md). The current input limit is 100 atoms per molecule.

This stable release covers the molecular-orbital viewer. NBO and related local-orbital views are in the separate [v0.4.0-pre.1 preview](v0.4.0-pre.1.md).

See the [user guide](../UI.md) for orbital browsing, diagrams, display controls and exports.
