# COV v0.3.0-pre.9 — Delocalised π orbitals

Adds grouped views of planar delocalised π systems and their participating atoms. Energy diagrams show the related orbitals together, and orbital details use clearer colours and Chinese/Japanese text.

This is an older preview. The current stable download is [v0.3.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.3.0).
