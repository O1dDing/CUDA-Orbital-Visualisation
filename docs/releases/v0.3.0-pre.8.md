# COV v0.3.0-pre.8 — Valence orbital analysis

Adds a chemical-valence view based on the calculation's atomic-orbital contributions. Orbital details include composition, σ/π/δ/φ character, Mayer indices and multicentre groups.

This is an older preview. The current stable download is [v0.3.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.3.0).
