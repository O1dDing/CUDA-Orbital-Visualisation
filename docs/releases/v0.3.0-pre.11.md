# CUDA Orbital Visualisation v0.3.0-pre.11 — Scoped Orbital Analysis and Validation

This prerelease advances PR #3 with independent numerical reconstruction checks, explicit orbital-analysis scopes, consistent diagram exports and details that remain usable after window resizing. It also indexes the existing REF-001 calculation and recovery archive.

## Highlights

- FCHK/FCH input, optional CHK conversion and Molden compatibility retain explicit source, occupation and density availability. AO overlap is independently integrated where required, while coefficient precision and angular conventions are preserved.
- Whole-orbital symmetry and local explanations retain their own point-group context, source members, spin, projections and residuals. Local labels do not replace missing whole-orbital information.
- Diagram snapshots preserve the actual drawn selection, exact member identities, alpha/beta values and export semantics. Crowded rows use separate lanes while preserving the energy transform.
- Metal/ligand values distinguish an actual zero from missing or inapplicable data. Crystal-field and pi-partner gaps have separate types, and topology explanations retain their molecular-skeleton witnesses.
- Details remain reachable after restoring or shrinking a maximized window. Colored chemistry text wraps within narrow sidebars; language and member context survive the interactions.
- CI builds commit-named Windows CUDA artifacts and checks the Blackwell payload. Branch updates no longer overwrite the historical pre.10 prerelease.

## Validation

The distributed ordinary and validation executables use measured source revision `3752f8afe7b1e5687f9960fb7f15cd7c591a3e79`. Later release integration changes are limited to workflow, documentation, archive indices and distribution files; the measured COV implementation is unchanged.

The full round recorded 187,792 native actions with zero failures, 31,871 sampled MOs, 1,214 complete frontier textures and 2,113 export bundles. Numerical, view and declared-model checks passed. Ordinary-viewer interaction and startup/load/exit from the distribution directory were checked separately.

Detailed reports, 83 recorded image files and their specified metadata are supplied in the validation-evidence archive. The full raw acquisition tree is retained separately; the public evidence bundle is not a duplicate of every texture, intermediate reference array or captured frame. Program identities, coverage and limits are recorded in the distribution manifest and [software validation record](../../validation/common-root-008e-20260912/README.md).

## Limits

Complete scientific acceptance remains zero. Software checks and candidate collection do not establish a physical ground state, geometry, chemical mechanism or universal symmetry assignment. The remaining physical work covers the original 273 references and at least 50 distinct external molecules, followed by aggregate acceptance.

One initial ordinary-viewer startup showed a blank client area. The same binary subsequently started normally four consecutive times, but the cause remains unknown and the observation is retained.

The existing native capability evidence accepts RAM pause for its recorded RPBE1PBE/UPBE1PBE installation. Optimization link-103 segmentation and analytic RWF restart remain unaccepted. RAM pause is not a disk save, and checkpoint parse success does not certify every restart route.
