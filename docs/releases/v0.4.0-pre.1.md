# Chemical Orbital Visualiser v0.4.0-pre.1

This preview adds NBO and related orbital views to COV. Alongside orbital energies, occupations and the energy diagram, you can explore how atomic and local orbitals contribute to a selected molecular orbital. Click an atom, bond or orbital to follow related values, then inspect selected orbitals in 3D.

## What's new

- Open an existing Gaussian FCHK together with the corresponding NBO output, or open a directory containing them. If several calculations are present, choose the one you want to inspect.
- Explore AO, NAO, NBO, NHO and NLMO views where the necessary data is available. Compare orbital composition, atom charges and related bond information without losing the original molecular-orbital view.
- Export energy diagrams and AO–MO relationship figures, with accompanying data files.

COV reads existing calculation results; it does not run Gaussian or NBO. If an optional file is missing, the ordinary molecular-orbital view remains available and affected analyses show that the data is unavailable. See the [AO–MO / NBO guide](../AOMO_NBO.md) for the controls and the meaning of the displayed values.

## Download and requirements

Download the Windows bundle from the [v0.4.0-pre.1 release](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0-pre.1). It includes `cov.exe`, launchers and example files. Gaussian, NBO and `formchk` are separate programs and are not included.

The supplied Windows build is for RTX 50-series GPUs and requires a compatible NVIDIA driver and OpenGL 2.1. Other NVIDIA GPU architectures need a suitable [source build](../BUILD.md). The current input limit is 100 atoms per molecule.

COV reads existing calculation results. Automatic orbital and bonding labels can be wrong; use the original output when interpreting them.
