# v0.4.0-pre.1 — NBO evidence integration (R16)

This prerelease adds the current NBO integration to the v0.3.0 stable baseline. It is a separate development line; the stable release remains the merged PR #3 implementation.

## Result

One evidence-aware consumer interface now selects between the legacy FCHK/AO provider and validated NBO capabilities. Absence, partial data, rejected association, unsupported derivation and genuine physical uncertainty are distinct. There is no global “NBO file exists” success switch.

- Keep total NPA charge separate from alpha/beta components and gate spin colours on validated capability, including restricted-open-shell input.
- Preserve typed selection for canonical, NBO, NAO, NHO, NLMO, SALC, weighted components, signed combinations and overlays; return to canonical and all export entry points preserve actual identity.
- Route MO composition and filters through complete validated NAO evidence, with Cor/Val/Ryd groups, norm, reconstruction residual and complete degeneracy groups. The original reference projection remains an explicit fallback.
- Integrate supported local-orbital/subspace relationships and collective pi analysis using the same Fock/KS operator, verified transformations and SVD evidence. No molecule-name or MO-number special cases are used.
- Store structured sigma/pi channels and traceable NPA graph evidence; retain distinct Mulliken/NPA and Mayer/Wiberg semantics.
- Show consistent display names and bonding summaries in the UI, clipboard and exports; add uniform analysis, active-view, integration, SALC and naming companions.
- Use adaptive nonlinear energy spacing for crowded diagrams, amber modified-scale values, and aligned side stacks. Preserve actual canonical energies, coefficients, occupations and spin.

## Recorded acceptance

The final ordinary and native-validation builds each passed 46/46 CTest tests. The saved R16 replay includes 12 capability-route inputs (absent, complete, partial, rejected association and independently rejected spin), 3,067 independent TiF6/acetylene/negative-control assertions, 159 Cr(CO)6 assertions, 196 identity/control/clipboard/three-export checks, 10 reattachment/cache checks, 17 saved-case categories, and focused XeF2/H2O/four-language checks. Actual ordinary windows were checked for O2, XeF2 and TiF6. Restricted-open-shell O2 local alpha/beta fields were independently reconstructed without inventing a missing FCHK beta canonical block.

See [all 16 audit items](../../validation/nbo-r16-20260927/ACCEPTANCE-16.zh.md), [acceptance gates](../../validation/nbo-r16-20260927/final-acceptance.json), [sources](../../validation/nbo-r16-20260927/SCIENTIFIC-SOURCES.md), and [source capture](../../validation/nbo-r16-20260927/source-capture.json). Raw replay evidence, failed attempts and resolved expectation migrations are preserved in the optional release evidence asset.

These are scoped software and numerical checks on recorded inputs, not universal scientific certification of every historical candidate or molecule. TiF6 low/high t2g groups remain triply degenerate; their separation and coupling singular values are not optical excitation energies, pi bond energies or a strict energy decomposition. NBO E2 and cross-Fock evidence are kept distinct. Low-symmetry or incomplete evidence may still have an explicit unsupported state. No new quantum calculations were run for publication.

No Gaussian, NBO, GenNBO or ORCA executables/licenses are distributed. Existing calculation outputs and historical source paths in raw evidence are retained as provenance, not promises that those paths exist on another computer.
