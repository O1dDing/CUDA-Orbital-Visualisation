# NBO and symmetry references

- [NBO 7 manual](https://nbo.chem.wisc.edu/nboman.pdf): reports, matrix transformations, archives, Wiberg indices and E(2) analysis.
- [Natural population analysis](https://nbo.chem.wisc.edu/ex_npa.htm): NPA charges and NAO populations.
- [MO/NBO tutorial](https://nbo.chem.wisc.edu/tut_cmo.htm): relationships between canonical and local orbitals.
- [Natural localized molecular orbitals](https://nbo.chem.wisc.edu/ex_nlmo.htm): main NBO components and delocalized tails.
- [NBO theory](https://nbo6.chem.wisc.edu/webnbo_css.htm): local orbital and bonding descriptions.
- [One-electron properties](https://nbo.chem.wisc.edu/ex_prop.htm): operator matrices and orbital contributions.
- [Hughbanks group-theory notes](https://www.chem.tamu.edu/rgroup/hughbanks/courses/673/lecturenotes/notes-6_689.pdf): projection operators and symmetry-adapted combinations.
