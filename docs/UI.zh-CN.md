# 使用 Chemical Orbital Visualiser

[English](UI.md)

本文对应 NBO 开发版。已发布安装包的打开方式见[下载说明](../README.zh-CN.md#下载)。

COV 用来查看轨道能量、电子占据和轨道之间的联系。打开计算文件后，可以浏览能级图、查看所选轨道的三维形状，并导出图像与数据。

## 打开计算文件

使用“打开文件”，将文件拖入窗口，或输入路径。FCHK/FCH 和兼容的 Molden 文件可直接打开。已安装 Gaussian 的 `formchk` 时，也可直接打开 CHK。

如果 COV 找不到 `formchk`，将环境变量 `COV_FORMCHK` 设为转换器的完整路径，然后重新启动 COV。也可以先用 `formchk` 生成 FCHK，再打开它。

v0.4 预览版可以打开计算目录，一并加载波函数和 NBO 文件；目录中有多个计算时，选择要查看的一个。每个输入最多包含 100 个原子。

## 浏览轨道与能量

使用搜索、HOMO/LUMO 跳转和内层、价层、虚轨道筛选。“全部”显示完整的导入列表。所选轨道的详情包含能量、占据、自旋，以及可用的对称性和轨道名称。

能量单位可以切换为 Ha、eV、J/mol、kJ/mol、cal/mol 或 kcal/mol。原始能量保留为 Hartree。

当前源码版在有对称性和出现顺序时显示 `2a₁` 等名称，也保留原 MO 编号和自旋；两者都可以搜索。接近的能级可以分组，详情保留各成员自己的能量。分组容差初始为 `1e-5 Ha`，可调整。

## 查看能级图

中心图显示已占据价轨道和附近的虚轨道。隐藏的内层或远端虚轨道仍可在完整列表中找到。选择轨道进行三维查看不会改变中心图的成员。

当前源码版可使用线性或非线性能量轴。非线性视图拉开拥挤能级，轴上标明能量值和单位。分组能级使用成员的平均能量。

“导出图与数据”保存 PNG、SVG、JSON 和 CSV。图片使用当前界面语言；数据包含轨道编号、能量、占据、自旋、分组和图中显示的成员。

## 查看分子与轨道

旋转、缩放分子，调整原子、键和轨道的显示。氢原子的可见性可以单独切换。轨道正、负相位使用不同颜色，等值面阈值可调整。

详情窗口可以移动、缩放和重新打开。界面支持中文、英文、日文和法文。

AO–MO 与 NBO 的文件准备和操作见[使用 NBO 结果](AOMO_NBO.zh-CN.md)。现有下载包的启动位置见[仓库首页](../README.zh-CN.md)。
