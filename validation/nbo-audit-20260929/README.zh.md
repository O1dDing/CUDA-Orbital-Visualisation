# NBO 接入补充审查：2026-09-29

本轮在 PR #5 的 `74a1e3c` 基线上检查是否还存在 NBO 主链路缺口。发现并修复了六类问题，以及普通窗口复测暴露的一个状态提示问题。当前支持范围内的 Gaussian/FCHK + NBO 主链路可以转入系统抓 BUG；这不代表任意输入均已验证，也不代表 ORCA 原生 NBO 关联已实现。

父任务保持唯一源码写入者与计算/构建调度者；两个只读子任务分别审查科学证据与产品状态。没有启动新的量子化学计算，没有安装或更换 ORCA。

## 本轮实际修复

| 问题 | 修复与验证 |
|---|---|
| SALC 占据来自未经独立验证的 canonical 占据重构；RO β 缺少直接 FCHK 轨道块时浪费已有密度证据 | 改为读取通过同自旋关联验证的 producer DENSITY，并按真实 AO 约定及重叠矩阵投影。占据、能量和 canonical 连线分别验证；没有构造 β 正则轨道块。单一 NAO 仍可保留已验证的原始占据；组合缺证据则不补值。 |
| π 角投影失败被误记为“不适用” | 明确区分没有受支持候选与候选证据不足；保存具体角投影、度量、维数、σ 泄漏等失败原因。部分候选成功时保留有效结果及其余失败原因。 |
| 报告内容改变但 integration/cache 身份不变 | 身份指纹涵盖 NAO 分类、NLMO 父关系/尾部、局域组分、E2 缺失语义、矩阵尺寸及来源、archive 几何/约定，以及 canonical 密度、占据/自旋来源和 AO 缩放。实际旧选择会被拒绝。身份版本变更会使旧缓存失效；不更改波函数物理量。 |

| 重新附加后沿用旧 Wiberg/E2 显示开关 | 在新 canonical、手动/自动 NBO 附加及失败清理时一致复位，再由当前能力启用。 |
| 普通窗口成功恢复或返回 canonical 后仍显示旧错误/NAO 提示 | 成功附加、无 NBO 加载、返回轨道集时更新顶部状态；普通窗口实际恢复复测和原生回放均通过。 |

## 剩余范围与下一阶段

核心功能不再需要另一套 UI 或更多逐分子特判。接下来优先做损坏/缺失矩阵、重复分析段、连续切换、重附加、复制/多入口导出的系统 BUG 回归，再接 ORCA 提供器。多中心归属、严格 SALC、π 方向等仍按可验证子空间给结果；证据不足明确保留原因，不等于物理上不可知。

目前基础加载器接受 FCHK 与 Molden，但 NBO 关联仍依赖已实现的 Gaussian AO/源身份约定；Molden 能打开不等于 ORCA+NBO 全路径通过。

ORCA 接入先使用已有计算输出，核验几何、基组顺序/纯球与笛卡尔约定、MO 身份/占据/自旋、重叠和密度，再复用统一能力路由。官方 ORCA 6.1 文档说明：

- [NBO 接口](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/nbo.html) 支持独立 NBO 6/7，并有 `NBOEXE` 和整数宽度要求；这些不是已验证的本机安装状态。
- [orca_2mkl](https://www.faccts.de/docs/orca/6.1/manual/contents/utilitiesvisualization/utilities.html) 可导出 Molden，其他轨道集必须保留自身身份，不能统一冒充 canonical。
- [orca_2json](https://www.faccts.de/docs/orca/6.1/manual/contents/utilitiesvisualization/orca_2json.html) 可提供结构/基组/MO；密度并非默认导出且需要对应密度文件。其 `FockMatrix` 的 F 是两电子贡献，完整算符还需单电子 H，不能直接把 F 当作完整 Fock 使用。

下一适配阶段应重复无 NBO、完整、部分、拒绝四种状态，并覆盖闭壳层/开壳层及不同 AO 约定。当前结论仅为已支持 NBO 路线收口及 ORCA 的接入前提，尚未宣称 ORCA 实装验收。
