# 下一轮密度来源控制

已生成 20 个 `.molden` / `.fchk` 数学控制及独立期望矩阵。`manifest.json` 保存输入哈希、解析 AO 重叠、70 位参考系数、P/Q 下三角数组、可用状态要求和变换关系。`generator.py` 是生成这些固定数据的原始脚本。

这些文件没有来自 Gaussian 的计算背书；FCHK 标题也明确标注数学控制。使用有限、归一化的 s 型 Gaussian AO 是为了排除随意系数或不正交基组造成的干扰，专门测试密度来源和输入模型。它们不是新外部分子，也不替代任何 OLD 案例。

共享整数占据的 Q 期望注明了所采用的单行列式解释；共享分数占据不强造唯一自旋分配。缺失与有效零值分别验收，完整 producer-format 密度与 MO 重构的完整性分别验收。矩阵控制阈值为预设 `2e-12`。
