## 已确认的来源缺陷与访问状态

- 2020 年论文打印页 246 / PDF 零基页 269 的 Table 74，标题含 `[Co@Ge10]`，但 `Sum formula` 行实为 `K3C54H104CoN10O17`，未列 Ge。已对页面图像核实，不是文本提取漏字。此表不能直接作为完整组成输入，需取得坐标、占据和精修模型核对。不会替作者默改公式。
- 两份学位论文是各自作者的研究来源；不同氨数的盐不是多个独立新增簇。不能把 h/e 比值接近理想值当成完整对称操作的证明。
- `PdBi10-CCDC.html` 的 HTTP 200 实际是验证码/条款页面，没有返回结构数据；`PdBi10-publisher.html` 的 HTTP 200 实际是自动访问验证页面，没有返回论文。二者均记为访问未完成，不执行验证绕过。
- Wiley SI 的本地请求返回 403，保留失败收据。索引能读取 SI 文本，不等于已在本机取得并核实其表格图像。
- TUM 两份 PDF 已存本地原件、SHA256、逐页文本及选定页预览；本地来源用于核对，不把完整版权文献复制进代码仓库。

`*.retrieval.json` 记录的是网络传输结果；本文/`source-review.json` 记录内容是否满足取证目标。两种状态不得合并。
