# 外部候选的初始三维坐标准备

67 个候选全部完成本次检索和数据完整性检查：35 个取得 PubChem 计算生成的三维构型；19 个已核对身份的候选没有可用三维记录，返回 404；13 个身份或实验坐标来源尚未落实的候选继续保留。

35 个已取得构型均通过原始字节哈希、CID、电荷、显式原子组成、坐标完整性和有限性检查，提供的分子图均为单个连通分量。其中 33 个组成与原 273 不同，另 2 个需要继续按实际化学图确认异构体差异。组成差异与这些完整性检查都不等同于几何、电子态或科学参考验收。

数据来自 [PubChem 官方 PUG REST 三维记录接口](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest)。CID 的三维构型属于计算生成的起始构型；它们不是实验结构，也不是本任务的 PBE0/def2 高质量参考。正式外部案例数、已接受质量参考数和已执行 Gaussian 数均为 0。

`summary.json` 汇总所有 67 个状态，`review-v1/summary.json` 保存数据身份核对、原子映射和已提供化学键的长度。每个成员的 `receipt.json` 指向原始响应及坐标规范化文件，不修改原响应。

第一版检索在处理标识符补查结果时，因记录字段形式不同中断。第二版按已裁决的 `matching_cids` 读取两类记录，校验并复用第一版已经取得的原始字节，随后完成全部成员。第一版脚本、成功数据和中断状态均保留，没有删去失败候选，也没有重复下载已取得的构型。

后续仍需确认化学图、立体构型、合理环境和电子态，并按计划做 Gaussian 优化、频率及适用的稳定性检查。入库前冻结正式结构身份，失败成员入库后持续保留。当前没有触发或控制用户独立管理的 `F:/CalChem/COV/Resume` 队列。
