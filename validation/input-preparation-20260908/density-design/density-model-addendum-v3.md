# 密度输入模型补充：不把共同推断当作独立证明

2026-09-08。承接 `density-source-contract-v2.md`。这是 NUM-FIX-006 冻结期间的下一轮准备，不修改当前程序、输入、检查器和判据。

## 新核对的来源边界

当前 `src/parser/molden_parser.cpp:559–563` 只要 Spin 文本不含 beta 就存为 Alpha；没有 Spin 行时也保留枚举默认 Alpha。`MolecularOrbital` 尚无单独的自旋字段来源。因而缺失/无法识别的字段不能在后续导出中变成“生产者提供 Alpha”。总占据可以足够计算 P，但仍不足以确认 Q，二者应分别保存可用状态。

冻结独立环境 `iodata/formats/molden.py:194–214` 将单一 α 空间读为 restricted，分别存在 α/β 时读为 unrestricted。其 `iodata/orbitals.py:200–247` 明确把缺少 alpha-minus-beta 占据时的推导写作 heuristics：整数共享占据按开放壳层处理，分数共享占据按闭壳层自然轨道处理。因此，COV 与这个默认推断相同本身不能证明真实电子态。

[Molden 官方格式](https://www.theochem.ru.nl/molden/molden_format.html) 给出的 Spin/Occup 是逐 MO 字段；后续解释应保留它们的实际存在性和所采用的共享/独立空间模型。当前任务以 Gaussian SCF FCHK 为主；不应为了统一 Molden 而削弱 FCHK 已明确提供的规范轨道与电子计数信息。

## 实施时的处理

1. 为“格式读取的自旋字段”和“恢复密度采用的轨道模型”分别记录来源、状态与解释依据。共享整数单行列式的常规解释可以保留，但必须有名称和适用范围，不能冒充额外的生产者元数据。
2. FCHK 规范共享空间依实际 α/β 计数与完整占据方向恢复；显式两自旋空间依各条轨道的自旋和占据恢复。Molden 的汇总计数不能重新按列表索引分配占据或未配对方向。
3. 对未声明自旋分区的共享分数占据，P 与 Q 分别判断。若无更多信息，Q 保持信息不足；不能把整数汇总或其他工具的闭壳层默认推断当成证明。
4. 已知 α/β 占据即使为分数，也可以形成明确的 P/Q；整数类型的总电子计数容器不能反过来取消这个有效结果。输出应另存可为实数的 trace/occupation sum，并标清集合/输入用途。
5. 解析拒绝、信息不足、需要明确输入用途与可用的有效零值分别保存。不会因 Q 缺项而清除与 Q 无关的可用 P、MO 和渲染。
