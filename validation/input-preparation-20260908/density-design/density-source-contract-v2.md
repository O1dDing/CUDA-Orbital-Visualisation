## 不依赖分子名称的反例与保护控制

使用真实有限 AO 基组及已解析归一化的两个正交 MO。可从两个相同指数的 s 函数出发，S12=s，取 c+=(1,1)/sqrt(2(1+s))、c−=(1,−1)/sqrt(2(1−s))。这些是输入契约的数学控制，不是新的平衡分子，也不计入外部 50 个。原始分子的系数、能量和占据保持原样。

| 控制 | 必须验证的结果 |
|---|---|
| 一条已知 Occup=2，另一条 Occup 缺失 | Occup 和完整 P/Q 保持缺项；已知贡献不能填补未知占据。真实后处理和下游消费者均不得给出虚假的完整密度/总键级。 |
| 共享空间逐 MO 占据按列表顺序为 [1,2,0]，再重排列表 | 总密度是单占 MO 的外积加双占 MO 的两倍外积，自旋密度只来自实际单占 MO；映射后必须与列表排列无关。全局 α=2/β=1 不能把未配对电子移到第二条 MO。 |
| 共享空间分数占据 [0.5,0.5] | 总密度可来自已知占据；聚合恰为整数不能证明自旋分解或把第一条轨道强制设为单占。按明确输入模型报告自旋信息不足。 |
| 共享空间分数占据 [1.5,0.5] | 同样保存已知 P；若 Q 无法唯一恢复，状态保持缺项而非 Derived 空数组。 |
| 显式 α/β 空间且各 Occup 已给出 | P=Πα+Πβ，Q=Πα−Πβ；包括自旋反转、独立轨道变号和 MO 排列改变。 |
| 明确闭壳层的完整整数共享空间 | 全零 Q 是 Available 的有效零矩阵，不能与缺项混淆。 |
| FCHK 只截去虚轨道，所有占据方向保留 | 仍能完整重构 P/Q，矩形系数应通过；不得强制 MO 数等于 AO 数。 |
| FCHK 截去占据方向，但电子计数仍声明其存在 | 重构空间不足；已有 producer P 可保持可用，但 MO 重构不能标为完整，也不能补造丢失轨道。 |
| 非有限占据、超出所声明波函数模型的占据或不匹配的维度 | 明确非法输入、用途不受支持或失败，不产生有限零值替代。带符号的差分密度可能是其他软件的合法输出，不能因此称整个 Molden 文件损坏；它也不能自动成为 COV 的普通电子态参考。 |

## 共享生产接口与消费者迁移

采用一个共享的密度重构结果，至少保存：矩阵布局、维度、数据、NumericalStatus、DataProvenance、producer 字段或推导方法、逐自旋输入模型、完整性及原因。原始 P/Q 与推导 P/Q 的身份不得混淆；保留实际生产对象，验证工具只序列化它。

- Available 表示矩阵确实可用，包含经过验证的零矩阵；只有此时 Producer/Derived 才承诺存在对应数值。
- MissingInput 包含缺少占据、无法唯一确定的自旋分区及缺少占据子空间，具体原因分别记录。
- InvalidInput、Failed 和 NotComputed 保留各自含义，不通过一个空 vector 隐藏差别。
- 对 FCHK 共享空间，逐索引规则必须由解析器声明的输入模型授权；对 Molden 的显式整数占据，按该 MO 的占据恢复自旋贡献，不重新排序填充。分数占据不能通过先聚合成整数来绕过歧义检查。
- 总 Mayer 指数需要完整、语义一致的 P/Q，或已经证明 Q=0 的共享闭壳层。若保留 P-only 的辅助分析量，必须用单独的定义与状态，不能继续命名为已完成的总 Mayer 结果，也不能无标记地驱动成键/结构图。
- 保留独立于密度的可用 MO、几何和渲染能力。某项密度缺项不应把所有不依赖它的功能清零。
- 普通版、验证版、实际界面、JSON/CSV 和真实导出使用相同的生产结果；现有 COV_VALIDATION 1 操作保持兼容。

## 实际密度的独立比较与打印精度

第一层核对实际生产 P/Q 是否等于独立读取的 Gaussian `Total SCF Density` / `Spin SCF Density`，按已经独立验证的 AO 顺序、相位与缩放协同变换。第二层核对 producer 文本密度与同一 SCF 轨道/占据重构的密度。两层分别保存结果，第二层不替代第一层。其他相关方法密度不能自动套用 SCF 轨道一致性检查；当前解析器明确选择的是 SCF 字段。

从每个实数 token 的尾数位数和指数建立打印舍入区间。逐元素传播至少包含 sum |n| (|Cj| δCi + |Ci| δCj + δCi δCj)，再加 P 字段舍入、必要的占据舍入以及单独记录的双精度运算误差。整数电子占据没有人为额外宽容度。先用正负指数、相消、极小量和不同打印精度的解析控制验证界限，再冻结检查器；不得因真实失败事后扩界。

同时报告 Tr(PS)、Tr(QS)、矩阵最大误差、带舍入界限的残差和可用状态。缺少已占据空间时不补造 β 数据或轨道。检查全部适用 α/β MO、纯/笛卡尔与矩形空间，ON/OFF 的实际矩阵与来源也必须一致。

实施应与作用域/来源模型的公共接口协调，先补真实入口控制和实际 P/Q 序列化，再冻结后续全 273 轮。此文未关闭任何既有问题，也未增加完整通过或正式外部分子数。
