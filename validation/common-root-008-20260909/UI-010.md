# UI-010：侧栏彩色长行挤到右边缘

UI-009 的新普通版桌面复验中，OLD-249 的英文“所选 MO 化学性质”原子对记录暴露了另一处旧问题：若一段彩色文字接在已经很长的行后，剩余宽度可能仅有几个像素，自动折行会把后面的文字排成窄竖列。详情还原修复自身已通过，但普通 UI 总体检查因此继续保持未完成。

根因是 `orbital_ui_dispatch.cpp` 的彩色连续片段无条件使用 `SameLine`。现在在放置下一段前检查实际剩余宽度；放不下时先换行，再让长片段在完整的内容宽度内折行。字段、百分比、贡献和 Mayer 数值的来源与格式保持不变。

`ui_details_resize_smoke` 扩展为通过真实 ImGui 帧调用生产绘制路径，在 500、350 像素面板和四种语言下比较新增一条原子对记录占用的实际行数。修改前英文 350 像素场景增加约 12.47 行并失败；验收上限为 8 行，防止窄竖列，同时允许正常的多行文字。

原始失败程序、构建和结果保存于 `F:\Codex\2026-09-09\new-chat\outputs\common-root-008d-details-20260912\before-wrap-fix-on-1789207739557440600`。修正后的当前版本仍须通过普通版实际画面、专项检查、固定 40 例及新版本全 273 例软件验证；没有增加完整科学验收通过数，也没有启动 Gaussian。
