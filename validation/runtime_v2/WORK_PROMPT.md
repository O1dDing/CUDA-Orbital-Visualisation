# REF-001 日常操作

入口、配置、迁移和回滚路径见 [README](README.md)，恢复边界见 [FAST_PAUSE](FAST_PAUSE.md)。

启动前使用 check 核对数据和资源，status 核对协调器状态。文件中的历史 PID 或状态不代表进程当前存活；必须同时查看 OS 锁、心跳和 Job 活动进程计数。不要删除锁文件绕过互斥。

临时让出算力用 4 暂停、6 恢复。内存暂停不刷新 Gaussian 缓存，不复制热 CHK/RWF，不运行 formchk，也不能关闭协调器或断电。5 展示暂停确认、扫描诊断和真实耗时；没有确认时不能当作暂停成功。

需要结束本次会话时，9 等当前阶段结束后退出；10 在边界停止派发；8 明确中断并尝试冷保存。只有所属树已全部退出、快照 manifest 已提交、哈希及 probe 有回执后才报告保存完成。保存正确不代表优化历史或解析 RWF 恢复能力已经验收。

恢复使用独立 attempt。原始归档、旧结果、失败记录和检查点始终保留，导入不改写原生产者身份。发现输入、基组、二进制、参考身份或文件校验变化时停止该案例并记录 needs_review。OLD-018 和 OLD-051 的现有 review 标记不会由迁移自动解除。

先使用明确的 --case 和 --limit 启动所需范围。--workers 1 可限制为一槽；两槽共享既有物理核与内存预算。调度器不自动做未指定的更高精度计算，candidate_collected 不能写成科学验收完成。
