# 2026-09-30 用户问题清单验收

基线：PR #5 的 bbadfa32942ccad62845dd6291dd97d0702d6143。本轮只由主代理写源码；三个只读子任务分别检查能量证据、读取性能和 SALC 伙伴身份。没有启动量化计算。

## 实施结果

- 四语言删除“分组能级取平均值”说明，将自动筛选说明统一为“已自动筛选轨道”及对应译文；分组均值行为、用户容差和原始数据不变。
- 密集侧轨道通过同一条可逆非线性轴保留完整纵向间距，去除挤压回高度上限的逻辑。原始能量未改；画布可纵向滚动。非线性刻度继续用琥珀色。
- 已证明的一次不可约表示伙伴块与全局序号分开保存。序号未知时仍能共名堆叠、逐个检视；不同片段/子空间及未分解的重复副本不会因同名合并。左右标签朝外。
- 限制性开壳层允许独立验证的物理自旋 Fock 侧能量。原 canonical 同算符门保留；新分支需要同源密度、完整局域变换、全部 NAO/NBO 打印能量以及已打印耦合/能隙交叉检查。侧能量可用不会生成 beta canonical MO 或 beta canonical 连线。
- NBO 能量表按 molecular unit 分段时，不再在第一个 Total Lewis 小计处提前结束。
- 矩阵数字读取消除重复正则扫描，保留原 std::stod 转换和 D/E 指数处理；父 NBO 标签只解析一次。首次附加复用同一套名称，普通视图不再构造仅供 validation 使用的部分 JSON。
